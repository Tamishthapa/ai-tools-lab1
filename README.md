# Artificial Intelligence Tools and Applications Lab

## Project Title
AI Tools and Applications Lab

## Purpose
This project is designed to explore the practical use of modern AI-assisted development tools in a software engineering workflow. It demonstrates how GitHub, GitHub Copilot, Visual Studio Code, and Python can be used together to build, test, and share simple but meaningful programming solutions.

## Tools Used
- GitHub
- GitHub Copilot
- Visual Studio Code (VS Code)
- Python

## Features Implemented
- hello.py: A simple Python script that prints a welcome message for the lab.
- sorting.py: Contains a Bubble Sort implementation that sorts a list of numbers in ascending order.
- utils.py: Includes an is_prime() function that checks whether a given integer is prime and correctly handles values below 2.

## Project Structure
- hello.py
- sorting.py
- utils.py
- README.md

## How to Run the Python Programs
Open a terminal in the project folder and run the following commands:

### 1. Run the hello script
```bash
python hello.py
```

### 2. Run the sorting example
```bash
python sorting.py
```

### 3. Run the prime-check utility
```bash
python utils.py
```

You can also test the prime function directly from Python:

```bash
python -c "from utils import is_prime; print(is_prime(13)); print(is_prime(21))"
```

## Conclusion
This lab provides a hands-on introduction to AI-assisted coding and Python development. By combining key tools such as GitHub, GitHub Copilot, VS Code, and Python, the project demonstrates how small software ideas can be developed efficiently and professionally in a collaborative environment.
